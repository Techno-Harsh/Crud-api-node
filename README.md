# 📝 Notes API (Node.js)

A JWT-authenticated REST API for managing personal notes.

## 🚀 Features
- User Registration & Login
- JWT Authentication
- CRUD operations on Notes
- User-specific data access
- MVC architecture

## 🛠 Tech Stack
- Node.js
- Express.js
- MongoDB + Mongoose
- JWT
- bcryptjs
